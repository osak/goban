# 碁盤

ブラウザで動く碁盤アプリです。PC・スマホの両方で使えます。TypeScript + Vite で書いています。

## 開発

Node.js 20.19 以降（または 22.12 以降）が必要です。

```sh
npm ci            # 依存パッケージのインストール
npm run dev       # 開発サーバー（http://localhost:5173/）
npm test          # テスト（Vitest）
npm run typecheck # 型チェック
npm run build     # dist/ に本番用ファイルを出力（型チェック込み）
npm run build:single  # dist-single/goban.html に 1 ファイル版を出力（型チェック込み）
npm run preview   # ビルド結果をローカルで確認
```

- `dist/` は相対パスで出力されるので、GitHub Pages などの静的ホスティングのどのディレクトリにもそのまま置けます。
  ES モジュールを使うため、`dist/index.html` をファイルとして直接開いても動きません。HTTP で配信してください。
- `dist-single/goban.html` は JS と CSS を埋め込んだ 1 ファイル版です。ダブルクリックで直接開いても動きます。

## GitHub Actions

### GitHub Pages での公開

`.github/workflows/deploy-pages.yml` がデフォルトブランチへの push のたびにテストと `dist/` のビルドを行い、
GitHub Pages に公開します（https://osak.github.io/goban/ ）。「Run workflow」から手動でも実行できます。

最初に一度だけ、リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」にしてください。

### 1 ファイル版

`.github/workflows/build-single.yml` が push のたびにテストと 1 ファイル版のビルドを行い、
`goban.html` を成果物 `goban-single` としてアップロードします（Actions の実行結果ページからダウンロードできます）。
「Run workflow」から手動でも実行できます。

## 機能

| 機能 | 操作 |
| --- | --- |
| 石を置く | 空いている交点をタップ（クリック） |
| 石を取り除く | 石をもう一度タップ |
| 置く石の色 | 「黒」「白」で同じ色を連打、「交互」で黒白交互。交互のときは「次: 黒／白」をタップで手番を入れ替え |
| ドラッグで一気に置く | 黒・白の連打中に空点からドラッグ（石の上から始めると続けて消せます） |
| 囲まれた石 | 「取り除く」（既定）／「△マーク」／「何もしない」から選択 |
| 着手番号 | 「着手番号」を「表示する」にすると、石を置いた順の番号を石に表示し、着手のログを表示。ログの手をタップするとその手から番号を付け直す（「次の手から」でこれから置く石だけに番号）。番号は「1から」（起点の手を 1 とする）と「手数」（何手目か）を切り替え |
| 座標ラベル | 盤の四辺に表示。設定で `A–T / 1–19` と `1–19 / 一–十九`（日本式）を切り替え |
| 部分拡大 | 「拡大」を押して範囲をドラッグ（タップするとその周辺 9 路を拡大）。「全体」で元に戻す。拡大中も表示中の線の座標ラベルを表示 |
| PNG 保存 | 「PNG」で表示中の範囲を座標ラベル付きで保存 |
| 元に戻す／やり直す | 「戻す」「進む」、または Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） |
| 設定 | 盤サイズ（19 / 13 / 9 路）、座標表記、見た目（木目／白黒）、盤面クリア |

補足:

- 「取り除く」モードでは、呼吸点のなくなった相手の石を取ります。取れないのに自分の石の呼吸点がなくなる点（自殺手）には置けません。コウの判定はしません。
- 「△マーク」モードでは、呼吸点のない連（黒白とも）に △ を表示します。
- 交互モードで石を取り除くと、その石の色が次の手番になります（置き間違いをタップで消してすぐ置き直せます）。
- 着手のログは石を置いた順の記録です。黒・白の連打で置いた石もそのまま記録されるので、通常の棋譜と食い違うことがあります（利用者の責任でお使いください）。
- 最後に置いた石をタップで消すと、置き間違いの修正としてログからも消えます。それ以外の石を消してもログには残ります（取られた石を手で取り除く場合など）。盤上にない石の手はログで取り消し線付きで表示し、番号は盤上に残っている石にだけ表示します。
- 「△マーク」モードで番号のある石には △ を付けず番号を表示します。PNG 保存にも番号が入ります。
- 盤面・着手のログ・設定・表示範囲はブラウザ内（localStorage）に保存され、再読み込みしても残ります。

## ファイル構成

```
index.html          画面
src/main.ts         エントリポイント
src/app.ts          UI（ポインタ操作・パネル・履歴・保存をつなぐ GobanApp クラス）
src/board.ts        盤面・石の配置と取り・呼吸点ゼロの連の判定
src/coords.ts       座標ラベル・星の位置
src/view.ts         表示範囲（拡大）
src/layout.ts       キャンバス上のレイアウト計算と当たり判定
src/renderer.ts     Canvas への描画（画面表示と PNG 出力で共用）
src/export.ts       PNG 出力
src/history.ts      元に戻す／やり直す
src/moves.ts        着手の記録（ログ）と石に付ける着手番号
src/persistence.ts  localStorage への保存と、読み込み時の検証
src/state.ts        アプリの状態の型と初期値
src/style.css       スタイル（スマホは縦並び、横長画面は右側に操作パネル）
plugins/single-file.ts  1 ファイル版を作る Vite プラグイン（JS / CSS を HTML に埋め込む）
tests/              Vitest のテスト（DOM に依存しない部分）
```
