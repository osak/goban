# 碁盤

ブラウザで動く碁盤アプリです。PC・スマホの両方で使えます。TypeScript + Vite で書いています。

## 開発

Node.js 20.19 以降（または 22.12 以降）が必要です。

```sh
npm ci            # 依存パッケージのインストール
npm run dev       # 開発サーバー（http://localhost:5173/）
npm test          # テスト（Vitest）
npm run typecheck # 型チェック
npm run build     # dist/ に本番用ファイルを出力（型チェック込み）
npm run build:single  # dist-single/goban.html に 1 ファイル版を出力（型チェック込み）
npm run preview   # ビルド結果をローカルで確認
```

- `dist/` は相対パスで出力されるので、GitHub Pages などの静的ホスティングのどのディレクトリにもそのまま置けます。
  ES モジュールを使うため、`dist/index.html` をファイルとして直接開いても動きません。HTTP で配信してください。
- `dist-single/goban.html` は JS と CSS を埋め込んだ 1 ファイル版です。ダブルクリックで直接開いても動きます。

## GitHub Actions

### GitHub Pages での公開

`.github/workflows/deploy-pages.yml` がデフォルトブランチへの push のたびにテストと `dist/` のビルドを行い、
GitHub Pages に公開します（https://osak.github.io/goban/ ）。「Run workflow」から手動でも実行できます。

最初に一度だけ、リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」にしてください。

### 1 ファイル版

`.github/workflows/build-single.yml` が push のたびにテストと 1 ファイル版のビルドを行い、
`goban.html` を成果物 `goban-single` としてアップロードします（Actions の実行結果ページからダウンロードできます）。
「Run workflow」から手動でも実行できます。

## 機能

| 機能 | 操作 |
| --- | --- |
| 石を置く | 空いている交点をタップ（クリック） |
| 石を取り除く | 石をもう一度タップ |
| △を付ける | 「置くもの」で「印」を選び、石をタップで △ を付ける／外す（ドラッグで続けて付け外し） |
| 文字を書く | 「置くもの」で「文字」を選び、入力欄に 1 文字（英数字・かな・漢字・記号・絵文字など）を入れて交点をタップ。石の上にも空いている交点にも書ける。同じ文字の交点をもう一度タップで消える（入力欄を空にするとタップした交点の文字を消す） |
| 置く石の色 | 「置くもの」の「黒」「白」で同じ色を連打、「交互」で黒白交互。交互のときは「次: 黒／白」をタップで手番を入れ替え |
| ドラッグで一気に置く | 黒・白の連打中に空点からドラッグ（石の上から始めると続けて消せます） |
| 囲まれた石 | 「取り除く」（既定）／「△マーク」／「何もしない」から選択 |
| 着手番号 | 「着手番号」を「表示する」にすると、石を置いた順の番号を石に表示し、着手のログを表示。ログの手をタップするとその手から番号を付け直す（「次の手から」でこれから置く石だけに番号）。番号は「1から」（起点の手を 1 とする）と「手数」（何手目か）を切り替え |
| 座標ラベル | 盤の四辺に表示。設定で `A–T / 1–19` と `1–19 / 一–十九`（日本式）を切り替え |
| 部分拡大 | 「拡大」を押して範囲をドラッグ（タップするとその周辺 9 路を拡大）。「全体」で元に戻す。拡大中も表示中の線の座標ラベルを表示 |
| 盤面の保存・切り替え | 「盤面」で保存した盤面の一覧を表示。一覧をタップで切り替え、「新規」「複製」「削除」、名前の変更。編集するたびに自動で保存 |
| SGF を開く | 「盤面」の「SGF を開く」で棋譜のファイルを選ぶと、新しい盤面として開く（1 つのファイルに複数の棋譜があればそれぞれ盤面にする）。本線の最後の局面を表示する |
| PNG 保存 | 「PNG」で表示中の範囲を座標ラベル付きで保存（ファイル名に盤面の名前が入る） |
| SGF 保存 | 「SGF」で盤面を SGF（FF[4]、UTF-8）で保存（ファイル名に盤面の名前が入る）。手順・変化・△・文字・盤面の名前・拡大範囲がそのまま入る |
| 元に戻す／やり直す | 「戻す」「進む」、または Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） |
| 設定 | 盤サイズ（19 / 13 / 9 路）、座標表記、△と文字（次の手に残す／手ごとに付ける）、見た目（木目／白黒）、盤面クリア |

補足:

- 「取り除く」モードでは、呼吸点のなくなった相手の石を取ります。取れないのに自分の石の呼吸点がなくなる点（自殺手）には置けません。コウの判定はしません。
- 「△マーク」モードでは、取られた石を盤上に残して △ を表示します。記録（手順）は「取り除く」モードと同じで、表示だけが違います。今の局面までの手順で取られ、その後その交点に石が置かれていない石に △ を付けます（コウの形で取った側の石に △ は付きません）。自殺手には置けません。
  - △ の石がある交点には、そのまま打てます（△ は外れます）。
  - 「取り除く」と「△マーク」を切り替えても記録は変わらないので、いつでも行き来できます。
- 交互モードで石を取り除くと、その石の色が次の手番になります（置き間違いをタップで消してすぐ置き直せます）。
- 着手のログは石を置いた順の記録です。黒・白の連打で置いた石もそのまま記録されるので、通常の棋譜と食い違うことがあります（利用者の責任でお使いください）。
- 最後に置いた石をタップで消すと、置き間違いの修正としてログからも消えます。それ以外の石を消してもログには残ります（取られた石を手で取り除く場合など）。盤上にない石の手はログで取り消し線付きで表示し、番号は盤上に残っている石にだけ表示します。
- 「何もしない」モードで、取りや自殺が起きるはずの石を置くと、SGF では取りの起きない配置（`AB` / `AW`）に、1 手として数える印（`GBMV`、下記）を付けて記録します。
- 手で付けた △ と文字は今の局面に付き、石を置くと次の局面に引き継ぎます（設定の「△と文字」で「手ごとに付ける」にすると引き継ぎません）。△ を付けた石が取られたり消されたりすると、その △ は引き継ぎません。△ は「元に戻す」の対象です。
- 番号のある石に △ が付くとき（手で付けた場合も、「△マーク」モードで囲まれた場合も）は、石いっぱいの △ の上に少し小さめの番号を書きます（番号は石の色で細く縁取って △ の線と重ならないようにしています）。PNG 保存にも番号と △ が入ります。
- 文字は交点に付くので、石を消したり取られたりしても文字はその交点に残ります。空いている交点では文字の後ろの線を消して書きます。△や着手番号のある石にも書けますが、その場合は重ねてそのまま描きます（見やすさは利用者の責任でお使いください）。文字は盤面ごとに保存され、「元に戻す」の対象で、PNG 保存にも入ります。「盤面をクリア」や盤サイズの変更で消えます。
- 入力欄に 2 文字以上入れると、最後に入力した 1 文字を使います。
- 盤面・着手のログ・設定・表示範囲はブラウザ内（localStorage）に保存され、再読み込みしても残ります。
  保存先はそのブラウザの中だけなので、別のブラウザや端末とは共有されません。
- 盤面は SGF のゲームツリーとして保存します（設計は [docs/design-sgf-core.md](docs/design-sgf-core.md)）。石を置くと手（`B[..]` / `W[..]`）、石を手で消すと配置（`AE`）、△ は `TR`、文字は `LB`、盤面の名前は `GN`、交互モードで入れ替えた手番は `PL` になります。置く石の色や座標の表記などの設定は全盤面で共通です。
  - 以前の版で保存した盤面は、初めて開いたときにこの形に移します（以前の版のデータは消さずに残します）。
- SGF 保存では、このゲームツリーをそのまま書き出します。拡大中は表示範囲を `VW` に入れます。SGF で表せないものは、次の独自のプロパティで入れます（ほかのソフトでは無視されます）。
  - `GBMV[]`: 「何もしない」モードで置いた、取りの起きない石（1 手として数える）
  - `GBNS[]`: 着手番号の起点（この局面より後の手から番号を付ける）
  - 番号を表示するかどうか・付け方は SGF には入りません。
- SGF の読み込みでは、文字コードを `CA` に従って読みます（なければ UTF-8、Shift_JIS、ISO-8859-1 の順に試します）。2〜25 路の正方形の盤の囲碁の棋譜だけを読み込みます。変化を含む棋譜も読み込めますが、今はまだ本線の最後の局面だけを表示します（変化の表示と手順の移動はこれから対応します）。
- 元に戻す／やり直すの履歴は盤面ごとに持ちます（ページを開いている間だけ。再読み込みすると消えます）。

## ファイル構成

```
index.html          画面
src/main.ts         エントリポイント
src/app.ts          UI（ポインタ操作・パネル・履歴・保存をつなぐ GobanApp クラス）
src/board.ts        盤面・石の配置と取り・呼吸点ゼロの連の判定
src/tree.ts         SGF と同じ形の不変のゲームツリー
src/game.ts         ゲームツリーから局面を導出する（打ち直し・着手の一覧・取られた石・キャッシュ）
src/edit.ts         タップ・ドラッグの操作をゲームツリーの編集に変える
src/ext.ts          独自の SGF プロパティ（GBMV / GBNS）
src/sgf/            SGF の読み込み（parse.ts）・書き出し（write.ts）・値の読み書き（values.ts）
src/sgf-file.ts     SGF ファイルの読み込み・書き出し（盤面との変換）
src/coords.ts       座標ラベル・星の位置
src/view.ts         表示範囲（拡大）
src/layout.ts       キャンバス上のレイアウト計算と当たり判定
src/renderer.ts     Canvas への描画（画面表示と PNG 出力で共用）
src/export.ts       PNG 出力・ファイルのダウンロード
src/history.ts      元に戻す／やり直す
src/moves.ts        着手の記録（ログ）と石に付ける着手番号
src/labels.ts       交点に書く 1 文字（1 文字の判定）
src/persistence.ts  設定の localStorage への保存と、読み込み時の検証
src/library.ts      保存した盤面の一覧（保存形式・検証・以前の版からの移行）
src/migrate.ts      以前の版の保存データをゲームツリーに移す
src/state.ts        設定の型と初期値
src/style.css       スタイル（スマホは縦並び、横長画面は右側に操作パネル）
plugins/single-file.ts  1 ファイル版を作る Vite プラグイン（JS / CSS を HTML に埋め込む）
tests/              Vitest のテスト（DOM に依存しない部分）
```
